## Verifier experiment

64 prompts: the first 32 of the canonical I-1 set (random words) and the 32 chat prompts in `kwh_host.experiments.CHAT_PROMPTS`. Greedy, 128 tokens, concurrency 32. Each prompt's output was generated by the reference model (W8A8) and by `hugging-quants/Meta-Llama-3.1-8B-Instruct-AWQ-INT4`, and both were scored by the reference model under teacher forcing.

`analysis.json` layout:

- `honest`, `awq_int4`: aggregates for all 64 requests and per kind, with position and request counts at each τ.
- `sparse_honest`, `sparse_awq`: every position where the output token was not the reference's top choice, as `[kind, request, position, gap, rank]`. Every other position had gap 0 and rank 1. `positions_per_request` gives each request's length.
- Both lists are in generation order: the 32 random-word requests, then the 32 chat requests. The kind letter is `c` for both (a slip in the condensing script), so tell them apart by order; rebuilt that way, the rows reproduce the per-kind aggregates exactly.
- `paired`: per prompt, the mean log-probability of each model's output under the reference.
- `texts`: the first six chat outputs of each model, truncated to 160 characters.

The uncondensed files (`gen-*.json`, `score-*.json`) were lost when the pod was stopped.
